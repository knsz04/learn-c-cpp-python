# C语言课程设计报告

## 商品库存管理系统

---

### 1 设计任务

#### 1.1 设计题目的描述

基于单链表开发超市商品库存管理系统，覆盖录入、查询、修改、统计、打印、文件存储六大核心模块。系统功能如下：

（1）**输入记录模块**：录入商品信息，包括商品编号、商品名称、分类、进货单价、售价、库存数量、供应商；

（2）**查询记录模块**：按商品编号、商品名称、商品分类检索库存商品信息；

（3）**更新记录模块**：新增商品、删除下架商品、修改价格/库存/供应商信息；

（4）**统计记录模块**：按商品分类统计库存总件数、库存总金额；统计库存不足（自定义阈值）商品清单；

（5）**输出记录模块**：全部商品库存信息表格化输出展示；

（6）**文件读写功能**：库存数据持久化存储，支持读取、写入本地文本文件。

#### 1.2 设计要求

（1）仔细审题，明确题目要求；

（2）按照结构化的程序设计思想，将程序模块化，将相对独立的功能写成函数；

（3）要求编程、调试通过并演示；程序编写规范，添加适当注释；

（4）按照课程设计报告的内容和格式要求，撰写课程设计报告，并且打印。

#### 2.1 数据的存储结构

定义的结构体以及单链表如下：

```c
typedef struct Goods {
    char id[MAX_ID];          // 商品编号
    char name[MAX_NAME];      // 商品名称
    char category[MAX_CATEGORY];  // 商品分类
    float buy_price;          // 进货单价
    float sell_price;         // 售价
    int stock;                // 库存数量
    char supplier[MAX_SUPPLIER];  // 供应商
    struct Goods *next;       // 链表指针
} Goods;

Goods *head = NULL;  // 链表头指针
```

**结构体字段说明：**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | char[MAX_ID] | 商品唯一标识符，最大20字符 |
| name | char[MAX_NAME] | 商品名称，最大50字符 |
| category | char[MAX_CATEGORY] | 商品分类，最大30字符 |
| buy_price | float | 进货单价，大于0的浮点数 |
| sell_price | float | 售价，大于0的浮点数 |
| stock | int | 库存数量，大于等于0的整数 |
| supplier | char[MAX_SUPPLIER] | 供应商名称，最大50字符 |
| next | struct Goods* | 指向下一个节点的指针 |

### 3 设计题目源代码清单

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <ctype.h>

#define MAX_ID 20
#define MAX_NAME 50
#define MAX_CATEGORY 30
#define MAX_SUPPLIER 50
#define DATA_FILE "goods.txt"

typedef struct Goods {
    char id[MAX_ID];
    char name[MAX_NAME];
    char category[MAX_CATEGORY];
    float buy_price;
    float sell_price;
    int stock;
    char supplier[MAX_SUPPLIER];
    struct Goods *next;
} Goods;

Goods *head = NULL;

void clearInput() {
    while (getchar() != '\n');
}

Goods* createGoods() {
    Goods *p = (Goods*)malloc(sizeof(Goods));
    if (p == NULL) {
        printf("内存分配失败！\n");
        return NULL;
    }
    p->next = NULL;
    return p;
}

int isIdExists(const char *id) {
    Goods *p = head;
    while (p != NULL) {
        if (strcmp(p->id, id) == 0) {
            return 1;
        }
        p = p->next;
    }
    return 0;
}

void freeList() {
    Goods *p = head;
    Goods *temp;
    while (p != NULL) {
        temp = p;
        p = p->next;
        free(temp);
    }
    head = NULL;
}

void loadFromFile() {
    FILE *fp = fopen(DATA_FILE, "r");
    if (fp == NULL) {
        printf("数据文件不存在，将创建新文件\n");
        return;
    }
    
    Goods *p, *tail = NULL;
    char line[500];
    
    while (fgets(line, sizeof(line), fp) != NULL) {
        p = createGoods();
        sscanf(line, "%[^,],%[^,],%[^,],%f,%f,%d,%[^\n]",
               p->id, p->name, p->category, &p->buy_price, 
               &p->sell_price, &p->stock, p->supplier);
        
        if (head == NULL) {
            head = p;
        } else {
            tail->next = p;
        }
        tail = p;
    }
    fclose(fp);
    printf("数据加载成功\n");
}

void saveToFile() {
    FILE *fp = fopen(DATA_FILE, "w");
    if (fp == NULL) {
        printf("文件打开失败！\n");
        return;
    }
    
    Goods *p = head;
    while (p != NULL) {
        fprintf(fp, "%s,%s,%s,%.2f,%.2f,%d,%s\n",
                p->id, p->name, p->category, p->buy_price,
                p->sell_price, p->stock, p->supplier);
        p = p->next;
    }
    fclose(fp);
    printf("数据保存成功\n");
}

void addGoods() {
    Goods *p = createGoods();
    if (p == NULL) return;
    
    printf("请输入商品编号：");
    scanf("%s", p->id);
    clearInput();
    
    if (isIdExists(p->id)) {
        printf("该商品编号已存在！\n");
        free(p);
        return;
    }
    
    printf("请输入商品名称：");
    fgets(p->name, MAX_NAME, stdin);
    p->name[strcspn(p->name, "\n")] = '\0';
    
    printf("请输入商品分类：");
    fgets(p->category, MAX_CATEGORY, stdin);
    p->category[strcspn(p->category, "\n")] = '\0';
    
    do {
        printf("请输入进货单价（大于0）：");
        scanf("%f", &p->buy_price);
        if (p->buy_price <= 0) {
            printf("进货单价必须大于0！\n");
        }
    } while (p->buy_price <= 0);
    
    do {
        printf("请输入售价（大于0）：");
        scanf("%f", &p->sell_price);
        if (p->sell_price <= 0) {
            printf("售价必须大于0！\n");
        }
    } while (p->sell_price <= 0);

        }
```

### 5 课程设计总结

#### 问题及解决方案

**问题1**：使用scanf读取整数或浮点数后，再使用fgets读取字符串时，会读取到残留的换行符，导致输入直接跳过。

**解决方案**：编写clearInput()函数，在每次使用scanf读取后调用该函数清空输入缓冲区中的换行符。同时使用strcspn()函数去除fgets读取到的换行符。

**问题2**：录入商品时可能输入重复的商品编号，导致数据混乱。

**解决方案**：在addGoods()函数中，输入商品编号后调用isIdExists()函数检查编号是否已存在，若存在则提示用户并释放已分配的内存。

**问题3**：用户可能输入无效的价格或库存值（如负数）。

**解决方案**：使用do-while循环对价格和库存进行输入校验，确保价格大于0，库存大于等于0。

**问题4**：程序退出时链表内存未释放，可能造成内存泄漏。

**解决方案**：在main函数退出前调用freeList()函数释放整个链表占用的内存。

**问题5**：数据文件不存在时程序崩溃。

**解决方案**：在loadFromFile()函数中检查文件是否成功打开，若不存在则提示用户并返回，程序会在后续操作时自动创建文件。
