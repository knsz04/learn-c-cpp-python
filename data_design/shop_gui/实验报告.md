## 4. 核心代码说明（含推理算法片段）

### 4.1 哈希表实现（商品管理）

**数据结构选择理由：** 商品查询是高频操作，哈希表的平均查找复杂度为 O(1)，适合商品SKU的快速定位。

```cpp
class HashTable {
private:
    struct HashNode {
        Product data;
        HashNode* next;
        HashNode(const Product& p) : data(p), next(NULL) {}
    };
    vector<HashNode*> table;
    
    size_t hash(const string& key) {
        size_t h = 0;
        for (char c : key) h = h * 31 + c;  // 多项式哈希
        return h % table.size();
    }

public:
    Product* find(const string& sku) {
        size_t idx = hash(sku);
        HashNode* node = table[idx];
        while (node) {
            if (node->data.sku == sku) return &node->data;
            node = node->next;
        }
        return NULL;
    }
};
```

**算法说明：** 使用链表法解决哈希冲突，哈希函数采用经典的多项式滚动哈希（31为经验系数），确保均匀分布。

### 4.2 小顶堆实现（库存预警）

**数据结构选择理由：** 库存预警需要快速获取库存最低的商品，小顶堆的堆顶元素即为最小值，时间复杂度 O(log n)。

```cpp
class MinHeap {
private:
    vector<pair<int, string>> heap;
    
    void heapify(int i) {
        int smallest = i;
        int left = 2 * i + 1;
        int right = 2 * i + 2;
        
        if (left < (int)heap.size() && heap[left].first < heap[smallest].first)
            smallest = left;
        if (right < (int)heap.size() && heap[right].first < heap[smallest].first)
            smallest = right;
        
        if (smallest != i) {
            swap(heap[i], heap[smallest]);
            heapify(smallest);  // 递归调整
        }
    }

public:
    void push(int stock, const string& sku) {
        heap.push_back(make_pair(stock, sku));
        int i = heap.size() - 1;
        while (i > 0 && heap[(i - 1) / 2].first > heap[i].first) {
            swap(heap[i], heap[(i - 1) / 2]);
            i = (i - 1) / 2;
        }
    }
};
```

**算法说明：** 插入操作先将元素置于堆尾，然后向上调整；删除操作将堆尾元素移至堆顶，然后向下调整（heapify）。

### 4.3 循环队列实现（订单管理）

**数据结构选择理由：** 订单处理是典型的FIFO场景，循环队列避免了普通队列的假溢出问题，空间利用率高。

```cpp
class CircularQueue {
private:
    vector<Order> arr;
    int front, rear, capacity;

public:
    bool enqueue(const Order& order) {
        if ((rear + 1) % capacity == front) return false;  // 队列满
        arr[rear] = order;
        rear = (rear + 1) % capacity;
        return true;
    }
    
    Order dequeue() {
        if (front == rear) return Order();  // 队列空
        Order order = arr[front];
        front = (front + 1) % capacity;
        return order;
    }
};
```

**算法说明：** 使用取模运算实现循环，`(rear + 1) % capacity == front` 判断队列满，`front == rear` 判断队列空。

### 4.4 红黑树实现（销售排行榜）

**数据结构选择理由：** 红黑树是自平衡二叉搜索树，保证插入、删除、查找操作的时间复杂度均为 O(log n)，中序遍历可得到有序序列。

```cpp
class RBTree {
private:
    enum Color { COLOR_RED, COLOR_BLACK };
    struct Node {
        SaleStat data;
        Node* left;
        Node* right;
        Node* parent;
        Color color;
    };
    
    void rotateLeft(Node* x) {
        Node* y = x->right;
        x->right = y->left;
        if (y->left) y->left->parent = x;
        y->parent = x->parent;
        if (!x->parent) root = y;
        else if (x == x->parent->left) x->parent->left = y;
        else x->parent->right = y;
        y->left = x;
        x->parent = y;
    }
    
    void insertFixup(Node* z) {
        while (z->parent && z->parent->color == COLOR_RED) {
            // 红黑树插入修正逻辑
            if (z->parent == z->parent->parent->left) {
                Node* y = z->parent->parent->right;
                if (y && y->color == COLOR_RED) {
                    // Case 1: 叔父节点为红色
                    z->parent->color = COLOR_BLACK;
                    y->color = COLOR_BLACK;
                    z->parent->parent->color = COLOR_RED;
                    z = z->parent->parent;
                } else {
                    // Case 2/3: 叔父节点为黑色
                    if (z == z->parent->right) {
                        z = z->parent;
                        rotateLeft(z);
                    }
                    z->parent->color = COLOR_BLACK;
                    z->parent->parent->color = COLOR_RED;
                    rotateRight(z->parent->parent);
                }
            }
            // ... 对称情况处理
        }
        root->color = COLOR_BLACK;
    }
};
```

**算法说明：** 红黑树通过5条性质保证平衡：根节点黑色、红色节点的子节点都是黑色、每条路径黑色节点数相同、新插入节点为红色。插入后通过旋转和变色恢复平衡。

## 6. 不足与改进方向

### 6.1 当前系统不足

1. **分类管理功能不完善**：当前仅通过categoryId字段记录分类，未实现树形结构的分类管理，无法支持多级分类展示。

2. **红黑树内存泄漏**：RBTree类中未实现析构函数，节点内存未释放，长期运行可能导致内存泄漏。

3. **堆数据未同步更新**：商品库存变化时，MinHeap中的数据未同步更新，可能导致预警信息不准确。

4. **无并发处理**：系统未考虑多用户同时操作的并发场景，可能导致数据不一致。

5. **日志记录缺失**：操作日志未记录，无法追溯历史操作和排查问题。

6. **界面交互体验**：GUI界面的交互方式较为简单，缺少快捷键支持、拖拽操作等现代化交互方式。

### 6.2 改进方向

1. **实现分类树形结构**：使用多叉树或邻接表实现商品分类的树形管理，支持分类的增删改查和层级展示。

2. **修复内存泄漏**：为RBTree添加析构函数，递归释放所有节点内存。

3. **实现堆数据同步**：在商品库存更新时，同步更新MinHeap中的对应数据，或采用懒加载策略每次重新构建堆。

4. **引入并发控制**：使用数据库事务或乐观锁机制，保证多用户并发操作的数据一致性。

5. **添加日志系统**：记录关键操作日志，包括操作人、操作时间、操作内容等，支持日志查询和导出。

6. **优化用户体验**：增加快捷键支持、数据导出功能、图表可视化展示销售趋势等。

### 6.3 扩展挑战功能展望

1. **商品关联推荐（图论）**：使用邻接矩阵表示商品关联关系，通过DFS算法实现商品推荐功能。

2. **历史价格趋势分析（动态规划）**：使用动态规划模型预测商品价格走势，辅助定价决策。

3. **多维度排序**：实现归并排序+多关键字比较，支持按价格、库存、销量等多维度排序。
